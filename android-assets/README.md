Launcher icons for the Android build (`.github/workflows/android.yml`).

The `java/` sources (home-screen widget and the bridge the web app uses to pass the place) are copied into the generated project.
Widget sizes: 1x1, 2x1, 2x2, 4x1, 4x2 (WindWidget) and 4x3, one receiver each; previews are drawn from a browser mock of the same layout.
