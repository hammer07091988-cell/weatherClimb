# weatherClimb

Wind at every height of a tower (2, 10, 20, 40, 80 and 120 m), with morning, day and evening forecasts, sunrise and sunset, UV and sea temperature. Data comes from [Open-Meteo](https://open-meteo.com).

Open it on a phone and choose "Add to Home Screen" to install it as an app. Russian and English are built in.
