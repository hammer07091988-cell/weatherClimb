# weatherClimb

Wind at every height of a tower (2, 10, 20, 40, 80 and 120 m), with morning, day and evening forecasts, sunrise and sunset, UV and sea temperature. Data comes from [Open-Meteo](https://open-meteo.com).

Open it on a phone and choose "Add to Home Screen" to install it as an app. Russian and English are built in.

## Android

The Android workflow publishes `weatherClimb.apk` on the [android release](https://github.com/hammer07091988-cell/weatherClimb/releases/tag/android). Send the file to a phone (Bluetooth, messenger) and open it to install. The app shows the live site, so web updates arrive without reinstalling.

## iPhone

Open the site in Safari, tap Share, then Add to Home Screen.
